## 二、代表性工作流与关键工程技法

### 1. 确定性时间驱动与导演闭环（`@xilo2991` / `Kianzzz/xilo-opus-video`）
- **核心架构**：网页暴露纯函数 `window.render(t)`，由 Playwright 逐帧调用截图后经 FFmpeg 管道合成 MP4。
- **可控工作流**：先提炼核心事实 / 测算音乐节拍 → 提供 3 个明显差异的方案并渲染关键帧/小样预览 → 确认后固化为 7 标签 XML `brief.md`（`<role>` / `<inputs>` / `<direction>` / `<structure>` / `<build>` / `<gotchas>` / `<start>`）→ 逐镜头制作并静帧质检 → 整片抽帧（含 360px 手机缩略图）+ 音频波形质检，6–7 项评分均达到 8/10 以上再交付。

### 2. Dribbble 级单元素闭式弹簧形变（`@twoclipping`）
- **连续形变**：整支片子用同一主容器通过尺寸、圆角、背景色插值形变，不硬切；文字切换时独立错开入场/出场时机防止叠字。
- **闭式弹簧叠加（无帧间状态）**：目标值多次变化时，将每次跳变对应的闭式欠阻尼弹簧响应累加：`v(t) = v0 + Σ (v_i - v_{i-1}) * spring(t - t_i)`。
- **液态指示器拉伸**：将元素左边缘与右边缘绑定不同刚度的弹簧（前沿快、后沿慢），自然产生类似流体/果冻的拉伸拖尾效果。
- **节拍网格与运动模糊**：按 `120 BPM` 节拍表在拍点触发状态变化；Playwright 启用 `--subframes 4` 配合 FFmpeg `tmix` 混合出电影级动态模糊。
- **清晰度坑点**：**切勿在被镜头缩放的元素或文字容器上设置 `will-change: transform`**，否则 Chromium 会锁死光栅化纹理导致放大变糊。

## 三、常见视觉风格配色与字体配方

1. **编辑部刊物纸感（Editorial Paper / Bento）**——适合方法论拆解、AI 工具演示、知识讲解
   - 底色：`#F5F1E8`（暖米纸色，可叠加极淡点阵或程序化噪点纸纹）
   - 辅卡面：`#EBE4D5` / `#FFFFFF`
   - 墨字：`#141413`（高对比主标题） / `#5C5850`（眉标与辅助说明）
   - 强调色：朱砂红 `#D9462F` 或 森绿 `#1F6E4A`
   - 字体栈：标题 `"Songti SC", "STSong", "Noto Serif SC", serif`；正文 `"PingFang SC", "Hiragino Sans GB", sans-serif`；编号/代码 `"SF Mono", "Menlo", monospace`

2. **复古像素 + CRT 显像管**——适合游戏史、极客工具、复古科技
   - 分辨率：内部离屏画布 `160x90` 或 `128x96`，`imageSmoothingEnabled = false` 整数倍放大；角色姿态按 `8–12fps` 量化，粒子保持 `30/60fps`；外层叠加 WebGL CRT 弧面、扫描线与荧光光晕。

3. **黑底金线精密科技（Dark Tech）**——适合架构讲解、硬件/大模型原理
   - 底色：`#0B0D10`（非纯黑），细线：`rgba(218, 178, 108, 0.45)`，高光：`#F0C97A` 暖金 + `#E8E6E1` 象牙白文字；搭配精密网格标尺与缓慢推近的 3D 线框模型。

4. **手绘笔记本（Sketch Notes）**——适合口播科普、概念拆解
   - 米白纸底 `#FAF7F0`，钢笔墨蓝 `#1D3557` + 单一高亮橙 `#E76F51`；线条随机扰动种子使用 `Math.floor(t * 12)` 实现 12fps 手绘沸腾感。

## 四、自媒体多平台画幅与安全区规范

制作时务必按平台参数设计响应式版式函数，切勿将 16:9 成片简单居中裁剪为竖屏：

| 平台场景 | 画幅比例 | 推荐分辨率 | 安全区与排版要点 |
|---|---|---|---|
| **B站 / YouTube / 西瓜视频** | `16:9` 横屏 | `1920x1080` | 四周留白 `>= 80px`，标题字号 `>= 56px`，正文 `>= 28px` |
| **抖音 / 视频号 / 快手** | `9:16` 竖屏 | `1080x1920` | **顶部避让 `140px`、底部避让 `340px`（标题/进度条）、右侧避让 `120px`（点赞评论头像）**；字号放大至 `>= 64px` |
| **小红书竖版视频 / 图文动态** | `3:4` 竖屏 | `1080x1440` | 顶部留 `100px`，底部避让 `220px`；上下卡片式构图尤佳 |
| **X / Instagram / UI 动效展示** | `1:1` 方形 | `1440x1440` | 中心构图占比大，适合单元素连续形变与循环播放 |
