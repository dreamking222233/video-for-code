<direction>
风格：编辑部刊物纸感 + Dribbble 级闭式弹簧微交互。画面干净克制，高对比纸墨排版，辅以极淡坐标点阵和胶片/胶带细节。
整片只用一套纸墨配色与统一眉标体系（左上角章节编号 // 01..04，中间时间线进度，右上角帧精确时间码）。
每个镜头只讲一件事，文字大而凝练，每屏停留 >= 2.2s，360px 手机缩略宽度下核心标题依然清晰可读。
动画全部采用欠阻尼闭式弹簧或 smoothstep 缓动，禁止匀速机械运动。
镜头：镜头 2 随弹簧光标焦点做轻微摄像机跟随推近；镜头间通过弹簧缩放/展开形成物理衔接，不使用无聊的纯黑屏硬切。
禁止：深色渐变背景 + 居中大字淡入的默认模板风格；元素切换时新旧文字重叠；缩放容器添加 will-change 导致文字模糊；外网字体或 CDN 图片；Math.random() 非确定性抖动。
</direction>

<structure>
节拍网格：120 BPM（每拍 0.50s，每 2.5s 一个小节/核心段落）

镜头 1｜0.00–2.50s（// 01 · 原理）
画面：第 0 帧即呈现主体——左侧深墨色代码卡逐行高亮 window.render(t)、spring()、ffmpeg.mux()；右侧是刊物大字「一行代码 渲染电影」与手绘风 12fps 沸腾感 SVG 贝塞尔轨迹及拍点脉冲。
动作：t=0.50s 大字沉稳弹簧升起；SVG 曲线随时间描边前进，每拍落红点。
声音：0.0s 软冲击起拍 + 0.5s 清脆 pop。
转场：2.25–2.50s 弹簧收束淡出，为 Bento 网格展开留出空间。

镜头 2｜2.50–5.20s（// 02 · 范式）
画面：2×2 四大代码引擎 Bento 卡片网格（01 Canvas 2D 整数放大像素动画、02 HTML/SVG 双边差异弹簧液态指示条、03 3D 透视旋转多面体+扫描线、04 14柱代码频谱可视化），上方明确标注「四大代码引擎 · 全场景覆盖」。
动作：精致矢量光标按拍点（2.85 / 3.45 / 4.05 / 4.65s）用闭式弹簧顺序点击 4 张卡片，镜头微弱跟随当前高亮卡片。
声音：2.5s whoosh 转场；每次点击对应 click/tick。
转场：4.95–5.20s 四卡同步收拢。

镜头 3｜5.20–7.80s（// 03 · 管线）
画面：横向 4 张带胶带细节的流程稿纸卡片（01 剧本分镜 -> 02 render(t) 网页 -> 03 Playwright 逐帧 -> 04 FFmpeg 混音），朱砂红连接箭头依次描边点亮；底部持续滚动 F001–F300 胶片帧轨。
动作：卡片错落摆正，t=6.75s 弹出森绿色倾斜确认印章「✓ 1080p · 30fps · -14 LUFS」。
声音：5.2s whoosh；5.8/6.3s tick；6.75s 清脆 success 提示音。
转场：7.55–7.80s 流程收束进取景器。

镜头 4｜7.80–10.00s（// 04 · 就绪）
画面：中央深墨色取景器画幅框（含 L 型角标与红点 REC），框内展示「CODE TO FILM / 代码视频工作流 · 已就绪」与朱砂红「成片」印章；底部依次点亮 16:9 横屏、9:16 抖音、3:4 小红书三枚画幅胶囊。
动作：t=8.0s 大字沉稳落定，胶囊依次点亮，稳稳停帧至 t=10.00s。
声音：7.8s whoosh；8.5s 明亮双音 success 和弦收尾。
</structure>

<build>
1. 画面：单 HTML 文件（离线零外网依赖），混合 DOM 排版 + SVG 描边 + Canvas 2D 高清/像素离屏渲染。
2. 暴露 window.render(t)，页面纯函数计算第 t 秒状态；随机数全部使用 seededRand；不使用 CSS transition/animation，不默认开启 requestAnimationFrame（仅 ?play=1 时允许预览）。
3. 渲染：Playwright 逐帧调用 window.render(t) 截图，FFmpeg 合成 1920x1080 30fps MP4。
4. 声音：audio/synth_music.py 用 numpy 合成 10 秒 48kHz 音轨并由 audio_tools.py 标准化到 -14 LUFS。
5. 质检：先渲 4 张静帧检查字体、对齐与留白，再渲染整片并导出 16 宫格抽帧与 360px 手机可读性拼图。
</build>

<gotchas>
- 绝不在缩放节点上写 will-change: transform，防止 Chrome 缩放光栅化模糊。
- 像素风子画布关闭 imageSmoothingEnabled 并整数坐标绘制，其余高清 Canvas 乘以 dpr=2。
- 镜头 1/2/3/4 严格控制进出场透明度和 pointer/layout 隔离，保证绝不发生跨镜头残影叠加。
</gotchas>
