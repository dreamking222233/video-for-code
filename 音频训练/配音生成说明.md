| 项 | 值 |

| 来源录音 | `/Volumes/文件/自媒体/音频训练/新录音.m4a`（2026-11-21 录制） |

`tts.py` 的默认音色已指向它，**不传 `--voice` 就用这个**。

### 为什么是它（实测数据）

同一句话、同一段录音，比对"合成结果的频谱包络"与"参考音频"：

| 音色 | 参考长度 | 包络相关 | 平均偏差 |
|---|---|---|---|
| cosy_v2 | 17s | 0.9824 | 5.52 dB |
| cosy_v2_24 | 24s | 0.9888 | 4.67 dB |
| qwen_v2 | 17s | 0.9913 | 1.56 dB |
| **qwen_v2_24** | **24s** | **0.9925** | **1.52 dB** ← 最优 |

1.0 = 与参考完全一致。**换模型比加长参考有效 5 倍以上。**

## 四、需要重新生成时

```bash
export DASHSCOPE_API_KEY=sk-xxx     # 只从环境变量读，禁止写进代码或提交
cd /Volumes/文件/自媒体/音频训练

python3 tts.py \
  --text-file <文案.txt> \
  --out <输出.wav> \
  --rate 1.45 \
  --unit sentence \
  --marks-out <时间轴.json> \
  --json
```

- **不要传 `--voice`**，默认已是 `qwen_v2_24`
- `--rate`：`1.0` 自然语速（≈4.7 字/秒）；`1.45` 接近现有剪辑节奏（≈6.5 字/秒）
- `--unit sentence`：一句一请求，输出逐句时间轴（对动画必需）
- `--lufs -18`：默认即此；设 `0` 关闭归一化
- stdout 只有一行 JSON，可直接解析：

```json
{"ok":true,"out":"/abs/path.wav","voice":"qwen_v2_24","duration_s":92.22,
 "chars_billed":1029,"est_cost_cny":0.144,"segments":6,"marks":"/abs/marks.json"}
```

退出码：`0` 成功 / `2` 参数或环境错 / `3` API 错 / `4` 音频处理错

### 长度对齐技巧

`rate` 不是严格线性。实测同 590 字文案：

| rate | 纯语音长度 |
|---|---|
| 1.38 | ≈94.7 s |
| 1.45 | ≈91.1 s |

想命中目标时长 L：先按 1.45 生成，量出纯语音 T，则 `新 rate ≈ 1.45 × T / (L − 0.22×5)`。

## 五、禁止事项

1. **不要修改** `/Volumes/文件/自媒体/音频训练/voices.json`
2. **不要调用** `create_voice` 重建音色（会生成新 voice_id，其它流程立刻失效）
3. **不要使用** `cosy_plus` / `cosy_flash` / `cosy_v1_legacy` / `qwen_plus`
   —— 这几个用旧录音（SNR 21 dB）训练，成品能测出 +15 dB 的高频嘶声
4. **不要改动** `音频训练/processed/` 下的参考音频
5. 不要自己写 HTTP 直调，`tts.py` 已处理分段（单请求 ≤340 汉字）、重试、拼接、归一

> 历史事故：07:46 有流程覆盖过 `voices.json` 的 `cosy_plus`，导致音色与配置不一致。写入前请先读，各自用独立 key。

## 六、计费

- 阿里百炼按**输入字符**计费，**1 个汉字 = 2 个字符**，输出音频不计费
- `qwen-audio-3.1-tts-plus`：1.4 元/万字符 ≈ **2.8 元/万汉字**
- 本片 590 汉字 ≈ 1029 字符 ≈ **0.14 元/次**
- 音色创建 0.01 元/个，账号有 1000 个免费额度

## 七、故障排查

| 现象 | 原因 / 处理 |
|---|---|
| `2` 退出、提示缺 DASHSCOPE_API_KEY | 没设环境变量 |
| `3` 退出、`BadRequest.ResourceNotExist` | voice_id 与 model 不匹配，或音色被删 |
| `3` 退出、`Throttling` | 触发 180 RPM 限流，脚本已内置重试 |
| 生成的音频比目标长 | 提高 `--rate`，见"长度对齐技巧" |
| 0.13s 停顿听着太赶 | 改用 `vo_qv2_92s22.wav`，或把 `--gap` 提到 0.25 |

## 八、质量验收

- 时长 = 目标（±0.05 s）
- `ffprobe` 显示 48 kHz / 1 声道 / pcm_s16le
- 真峰值 ≤ −1.5 dBFS，无削波
- 4–12 kHz 频段能量与参考音频相差 ≤ 5 dB（当前 −30 dB 级，说明无高频嘶声）
- 混音后整体 −14 LUFS
